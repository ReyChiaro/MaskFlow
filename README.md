# 🌊 MaskFlow

> <u>**Models**</u>: This repository is the official implementation of paper "🌊 MaskFlow: Consistent and Seamless Region Image Editing with Masked Flow-Matching", including:
>
> - Model pipelines
> - Timestep schedulers
> - Trainer and training scripts
> - Evaluators
>
> <u>**Dataset**</u>: The dataset can be found in [🤗MaskEdit](https://huggingface.co/datasets/ReyChiaro/MaskEdit)
>
> **<u>Online Demo</u>**: We provide an [online demo](https://github.com/ReyChiaro/EditOnline.git) for open-world testing, the repository for online demo is open released in [🪄 EditOnline](https://github.com/ReyChiaro/EditOnline.git)
