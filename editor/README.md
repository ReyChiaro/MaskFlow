# MaskFlow Editor

一个轻量的本地图像区域编辑器。核心流程只有四步：

界面默认使用英文，可通过右上角的 `中文 / EN` 按钮随时切换中英文。

1. 上传原图。
2. 在图上绘制 mask；可调笔刷、擦除、撤销、清空或保存 mask。
3. 输入 prompt，并按需调整推理参数；模型、LoRA 和 pipeline 参数默认折叠。
4. 启动推理，查看任务进度，预览并保存生成结果。

## 启动

在项目根目录执行：

```bash
uv run python -m editor
```

然后访问 <http://127.0.0.1:7860>。

请通过这个本地地址进入编辑器，不要直接双击 `static/index.html`。直接打开 HTML 虽然可以显示基础页面，但浏览器无法连接模型状态、任务进度和推理接口。

如需修改端口：

```bash
uv run python -m editor --port 8080
```

编辑器只监听本机地址。没有 CUDA GPU 时仍可正常制作和保存 mask；模型加载和推理需要适合当前模型的 GPU 环境。首次推理会下载基础模型及所选 LoRA，随后在进程内复用已加载的模型。

每次任务会把原图、mask 和结果保存到 `outputs/editor/` 下，网页中的保存按钮也可直接下载 mask 和结果图。
